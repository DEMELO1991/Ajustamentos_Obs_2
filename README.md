# Ajustamento de Observações com Controle de Qualidade

Este repositório foi criado para desenvolver e apresentar um projeto individual da disciplina de Ajustamento de Observações e Geodésia Aplicada.

## Autora

Andreza dos Santos Rodrigues de Melo

## Objetivo

Aplicar os conhecimentos teóricos e práticos sobre ajuste de observações, com foco no controle de qualidade, medidas de confiabilidade e detecção de outliers. O projeto utiliza dados simulados e exemplos em Python com execução no Google Colab.

## Estrutura do Repositório

O repositório contém os seguintes arquivos e pastas:

- `data/entradas.csv`: dados de ângulos e distâncias
- `data/pontos_apoio.csv`: coordenadas conhecidas do ponto de apoio
- `notebooks/ajuste_colab.ipynb`: notebook com os cálculos e explicações
- `src/ajuste_utils.py`: funções auxiliares
- `README.md`: este arquivo com as informações principais

## Precisão adotada

- Precisão linear: 3 mm + 2 ppm
- Precisão angular: 5 segundos

## Conteúdo do Projeto

O trabalho está dividido nas seguintes partes:

1. Introdução ao ajuste de observações
2. Histórico dos métodos de controle de qualidade
3. Modelagem matemática e deduções utilizadas
4. Exemplo de aplicação com dados simulados
5. Detecção de outliers e análise dos resíduos
6. Cálculo das matrizes de variância-covariância

## Execução
